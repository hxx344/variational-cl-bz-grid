# 网格监控页设计与数据约定

任务是监控三种间距的模拟表现、查各层仓位、回看已平仓损益。默认间距为三日平均价差中枢绝对值的 0.5%、1%、2%，每侧覆盖 30%，分别为 60/30/15 层，总跨度均为 60%。顶部先展示策略对比，再展示同轴盈亏曲线与价差/三日中枢，最后按策略查看网格占用和交易明细。独立模拟账户的权益不求和为“总账户收益”。策略卡同时显示百分比、每侧范围、总跨度、当前价差上下限、当前一格 USDC/桶、累计成交额与桶数；累计口径为实验启动以来所有双腿开平仓，独立于图表时间筛选。持仓明细列出按开仓中枢固定的净止盈目标。

沿用 Python 标准库、原生 DOM 与 SVG，不引入编译和外部 CDN。两张主图各最多 900 个采样点、最多 3 条主要比较曲线；每 10 秒轮询，隐藏标签页停止轮询，失败保留旧图。查询范围是最近 1h / 24h / 7d，以服务器最后成功样本结束；超过 900 点按区间保留各指标高低点。跨行情中断断线，采样口径和缺失状态就近说明。

设计色：背景 #eef3f8、主文 #183247、蓝 #285de5、青 #098477、琥珀 #b47818；比较类别蓝/青/琥珀，盈亏正负另用绿色/红色并同时显示符号。字体用系统中文无衬线，金额采用等宽数字。桌面为策略对比行、宽盈亏图与窄价差图、明细区；手机保留紧凑策略摘要与主图，双腿明细变为行卡，不把桌面整图缩小。

图层：盈亏折线（同轴、包含零、当前数值可直接读）；价差与中枢（共同价格轴，虚线代表中枢）；网格占用（60/30/15 个层级槽位按行换行，不缩小点击区域；占用方向与桶数的文字标签）；表格（查持仓与平仓逐笔记录）。主路由 dashboards-and-real-time-visualization，SVG 图层按 d3-data-visualization 的缩放/标注规则，本地完成各层独立检查，无委派。

选择的策略、时间范围和明细标签页写入 URL，刷新、返回保持选择；无效值回退默认。主要按钮至少 44px，支持键盘、点击图表或采样滑块查看历史点，不依赖悬停。CSV 导出为当前加载且筛选后的平仓记录，最多每策略最近 100 笔，明确说明不是全部历史。无 JavaScript 时保留原来的静态报表。

网页为模拟监控，独立进程仅绑定 127.0.0.1，通过 SSH 转发查看。提供固定静态资源、dashboard JSON、静态报告及排队式模拟重置；不提供文件浏览、会话、下单或参数修改接口。SQLite 只读连接；以最后发布的共同样本时间截断仓位/平仓记录与旧账本成交量，浮动损益使用该样本数量对应的 bid/ask、滑点与开平手续费计算。显示北京时间，源数据仍用 UTC。

验收：浮动损益之和等于总损益减已实现；已完成快照之前/之后的仓位过滤正确；采样降密保留峰谷且时间断点不连线；新/旧账本、空仓、无数据、暂停、停止、断线状态；白名单路由阻止目录/会话访问；安装升级保留原配置与账本。浏览器检查桌面和 390px 手机布局、筛选、历史点、标签页、刷新恢复及 CSV；测试限于数据契约和关键行为。

## 本次验收记录（2026-09-19）

- Windows Python 3.11 与 WSL Ubuntu Python 3.12 各运行 64 项 Python 测试，平台不适用项跳过；6 项 Node 前端逻辑测试通过。
- 浏览器读取现有模拟账本，确认三组持仓、方向、桶数、成本与浮盈亏；策略筛选、时间范围、刷新恢复、键盘标签切换和浏览器返回通过。
- 单独生成合成行情账本验证 1,200 次采样、多页平仓记录、暂停/过期提示；CSV 实际下载 100 条选定策略记录，日期包含年份。合成数据未写入现有模拟账本。
- 浏览器尺寸覆盖接口未生效，改用独立的 390px iframe 验收外壳检查响应式布局（仅测试服务器允许 iframe）。有效内容宽度 375px，无页面横向溢出；生产页面继续禁止被 iframe 嵌入。
- 停止测试网页服务后，页面显示断线提示并保留原有 15 条当前分页记录；不会清零盈亏。
- 内存数据库中 60,481 条七天采样查询与降密约 0.47 秒；此为本机测量，不代表服务器性能承诺。

部署验证为隔离 Linux 安装测试，涵盖网页 unit、启动、模式切换和数据保留。用户服务器仍需执行更新命令；没有把本地预览描述成已在远端部署。

- Windows 原生 Python 运行 84 项测试，72 项通过、12 项按平台跳过；7 项 Node 测试通过。本次未使用 WSL。

## 每侧30%范围修正（2026-09-20）

三组改为每侧60/30/15层，范围均为中枢上下各30%。在中枢4的隔离合成行情上，桌面与390px手机显示2.8000～5.2000、总跨度60%；网格分别展示60/30/15个格位，最后一层标记30%，无横向溢出或浏览器脚本错误。自动测试覆盖双向边界、中心变化、资金约束与旧配置迁移。

## 三日窗口与重置交互（2026-09-24）

沿用两张 SVG 图与 DOM 表格，不增加图实例或轮询负担。中心窗口由数据中的 `center_window_hours` 驱动；旧7日数据只读兼容，不能标成3日。每张策略卡新增当前双腿名义金额、开仓额度和保证金用量；数字由服务端 Decimal 计算，单位 USDC，不与累计成交额混淆。

重置入口在页首，使用原生 dialog，触屏/键盘均可操作并支持取消。确认说明作用于全部组、归档后清零、恢复各组资金。状态为等待执行/归档清理/完成/失败；请求失败不自动重发。后台重置期间不发布部分清理结果，完成时清除历史选点和分页，旧轮与新轮不连线。所有历史仍在归档中；无脚本报告保留只读用途。URL 策略、时间与明细筛选不改变重置范围。

重置写入口要求同源、JSON 和随机请求头，拒绝陈旧代次；仅绑定 localhost。网页不直接写持仓 SQLite，唯一模拟 writer 负责归档和清理。验证覆盖历史窗口、旧身份、迁移幂等、归档失败、部分清理中断恢复、重复请求、跨域拒绝及桌面/手机交互。
