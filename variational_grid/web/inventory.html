库存定义与模拟口径

先将 CL 多头 scalp、BZ 空头 scalp、CL / BZ 普通价格网格与反向价差网格（默认做多 BZ、做空 CL）汇总为真实模拟账户的两条净仓位 qCL、qBZ；多头为正，空头为负。方向偏离比例 = |qCL + qBZ| ÷ (|qCL| + |qBZ|)，两腿都为零时为 0。容忍度基于实际净桶数，不是美元名义金额比。

方向桶数 = qCL + qBZ；价差桶数 = (qBZ − qCL) ÷ 2。纠偏同时向两腿调整相同的有符号桶数，保持价差暴露不变；原始方向桶数指纠偏前的策略目标合计。0% 为方向中性目标，不限组不主动纠偏。交易数量步长可能留下无法精确归零的残差，页面保留真实结果。

净仓位按同一帧行情估值。执行成本包含成交相对共同标记价的价差、滑点和手续费，也可能因报价时差有利而为负；退出储备估算现存仓位退出成本，已计入净浮盈亏。手续费和纠偏成本都是执行成本的组成部分，不再重复扣除。收益归因是账户持仓随市场价格变化的方向 / 价差分解，不是各策略模块的收益相加。

风险表的超参考阈值时长使用所有组共同的参考比例；本组超阈值时长使用该组自身容忍度。观测时长排除超过 max(60 秒, 采样周期 × 3) 的行情缺口。保证金按各组配置杠杆估算，杠杆不倍增桶数或损益。未计资金费与实际强平机制。历史曲线可能降采样，明细为最近已发布的共同采样；短期模拟结果不足以确定长期优劣。
